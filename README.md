# jobapp

Alfredo's job-search tooling (2026): scans startups.gallery companies against Ashby / Greenhouse / Lever boards for remote ops, CoS, CS/support ops, deployment and ops-PM roles, filters by stage and fit, and builds the tracker digests.

- sweep*/: board scans and filters (scan.py, filt.py, agg.py)
- gscan/: Gmail application scan and digests
- gd/: Glassdoor company lookups

Personal data (résumés, contacts, tracker exports) is intentionally not in this repo.
